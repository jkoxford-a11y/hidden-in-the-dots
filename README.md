# Hidden in the Dots

Press and hold: random dots become a dog. A phone-first demo of the Gestalt principle of common fate (things that move together are seen as one thing).

Live: https://jkoxford-a11y.github.io/hidden-in-the-dots/

Every dot moves at the same speed and lives for under half a second, so a still frame shows nothing. While you hold, the dots inside the dog's outline share one direction; all others wander. Add `?debug` to the URL to color the dog's dots.

Built for the ACT 2026 symposium "Blueprint First" (Jon K. Oxford & Darah Oxford).
